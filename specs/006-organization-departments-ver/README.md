# Feature 006: Organization Departments Management

## Overview

Hierarchical department management system with tree structure for Tech Office platform. Enables organizations to create nested departments, assign managers, organize employees, and visualize organizational structure.

## Key Features

- 🌲 **Hierarchical Tree Structure**: Unlimited department nesting (root → children → grandchildren, etc.)
- 👥 **Employee Assignment**: Single department membership per employee
- 👔 **Manager Designation**: Department managers with limited permissions
- 🔒 **RBAC Permissions**: ROLE_OWNER/OPERATOR full control, managers restricted
- ⚠️ **Warning Indicators**: Visual alerts for empty departments (no manager/members)
- 🚫 **Circular Prevention**: Validation to prevent department → descendant moves
- 📊 **Cached Counts**: Performance-optimized member/manager/child counts
- 🏢 **Multi-Tenant**: Organization-level isolation enforced

## Architecture Summary

### Backend
- **Database**: Extends `organization.department` and `organization.department_member` tables
- **Tree Structure**: Self-referencing `parent_department_id` foreign key
- **Triggers**: Auto-maintain cached counts (member_count, manager_count, child_count)
- **Queries**: Recursive CTEs for tree traversal, validation for circular references
- **Service**: `DepartmentService` with AdminPool (system) and TenantPool (user ops)
- **RPC**: 11 methods (CRUD, employee assignment, tree operations)

### Frontend
- **Location**: `workspace/organization` (new "Departments" tab)
- **Components**: MUI TreeView with custom nodes, warning indicators
- **Drag-and-Drop**: @dnd-kit for department moves (OWNER/OPERATOR only)
- **State**: TanStack Query for server state, local state for UI
- **Permissions**: Manager vs admin UI variants

## Quick Reference

### Schema Changes
```sql
-- Add to organization.department table:
ALTER TABLE organization.department 
  ADD COLUMN parent_department_id UUID REFERENCES organization.department(id),
  ADD COLUMN member_count INT DEFAULT 0,
  ADD COLUMN manager_count INT DEFAULT 0,
  ADD COLUMN child_count INT DEFAULT 0;

-- Add unique constraint (single department per employee):
CREATE UNIQUE INDEX idx_one_department_per_employee 
  ON organization.department_member(organization_id, employee_id);
```

### Key RPC Methods
- `GetDepartmentTree` - Retrieve full hierarchy (all roles)
- `CreateDepartment` - Create with optional parent (OWNER/OPERATOR)
- `MoveDepartment` - Restructure hierarchy (OWNER/OPERATOR)
- `AssignEmployeeToDepartment` - Add employee (managers restricted)
- `SetDepartmentManager` - Designate manager (OWNER/OPERATOR)
- `DeleteDepartment` - Remove empty departments (OWNER/OPERATOR)

## Edge Cases Handled

- ✅ Empty departments (no manager/members) allowed with warnings
- ✅ Circular reference prevention (validation before move)
- ✅ Department deletion blocked if members/children exist
- ✅ Manager loses privileges when moved to different department
- ✅ Unique constraint ensures single department membership
- ✅ Triggers maintain count accuracy even during race conditions
- ✅ ON DELETE CASCADE/RESTRICT prevents orphaned records
