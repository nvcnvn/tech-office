# Feature Reference

Last reviewed: 2026-06-18

Tags: `feature-reference`, `lookup`, `owner`, `it-admin`, `employee`, `available now`, `role-dependent`, `mobile in progress`

Use this page when you want to look up what TechOffice can do. Use the owner/admin and employee guides when you want step-by-step instructions for a specific task.

## Account Access

What it does:

- Organization registration and subdomain resolution.
- Email/password sign-in.
- Google and Apple SSO.
- Password reset and password change.
- Invitation acceptance.
- Organization switching.
- Active session listing and logout.
- PIN-based organization accounts for workers without daily email access.
- Profile updates.

Common tasks:

- Register a new organization.
- Sign in with email, SSO, or account ID plus PIN.
- Reset a password or PIN.
- Switch organizations before acting.

Related guides: [Register Your Organization](03-admin-guide.md#1-register-your-organization), [Sign In to the Right Workspace](04-employee-guide.md#1-sign-in-to-the-right-workspace)

## Organization Management

What it does:

- Employee list and employee cards.
- Single employee creation.
- Bulk employee import with preview and execution.
- Department tree management.
- Department manager assignment.
- Employee movement between departments.
- Permission and role management.
- Org-managed account create, list, unlock, deactivate, and credential reset.

Common tasks:

- Create departments before importing employees.
- Invite employees individually.
- Import employees from a spreadsheet.
- Create a PIN account for a low-email worker.
- Delegate admin work with roles.

Related guides: [Set Up Departments and Managers](03-admin-guide.md#3-set-up-departments-and-managers), [Invite Your Team Members](03-admin-guide.md#4-invite-your-team-members), [Delegate With Roles and Permissions](03-admin-guide.md#5-delegate-with-roles-and-permissions)

## Notifications and Presence

What it does:

- Notification list with unread state.
- Read, mark-all-before, and soft delete actions.
- Source-domain filters.
- Unread count.
- Live SSE stream for in-app delivery.
- Browser and mobile push token registration.
- Presence status and visibility settings.
- Active connection tracking for real-time routing.

Common tasks:

- Check unread notifications.
- Open a notification to jump to the source.
- Enable push notifications on trusted devices.
- Set presence visibility.

Related guides: [Prepare Notifications, Chat, Docs, and Files](03-admin-guide.md#9-prepare-notifications-chat-docs-and-files), [Check Your Notifications](04-employee-guide.md#2-check-your-notifications)

## Chat and Voice

What it does:

- Public and private channels.
- Direct messages.
- Channel member management.
- Messages, replies, reactions, edits, and deletes.
- User and department mentions.
- Typing indicators.
- Per-channel notification preferences.
- File attachments.
- Voice messages with playback.
- Channel voice calls, invitations, join/leave/end, call records, recordings, and transcript artifacts.

Common tasks:

- Create a team or project channel.
- Start a direct message.
- Reply to a specific message.
- Mention a person or department when action is needed.
- Send a voice message or join a live call.

Related guides: [Prepare Notifications, Chat, Docs, and Files](03-admin-guide.md#9-prepare-notifications-chat-docs-and-files), [Use Direct Messages, Group Chat, and Task Discussions](04-employee-guide.md#3-use-direct-messages-group-chat-and-task-discussions)

Common tasks:

- Assign project members.

- Free/busy and suggested slots.
- Calendar resources and resource access control.
- Booking links and slot claiming.
- Delegation.
- Event check-in and evidence.
- Audit entries.
- Cross-domain overlays.
- Calendar search.

Common tasks:

- Create a meeting or event.
- Respond to an invitation.
- Check availability.
- Add a room, vehicle, or equipment resource.
- Create a booking link.

- Secure download URLs.
- Metadata and batch metadata.
- File listing.
- Delete and batch delete with deletion detail.
- Quota view and update.
- Magic byte validation.
- Access rules and access checks.
- File search.
- PDF conversion status and retry.
- Content indexing status.

Common tasks:

- Review storage usage.
- Delete stale files with a reason.
- Understand file validation warnings.

Related guides: [Prepare Notifications, Chat, Docs, and Files](03-admin-guide.md#9-prepare-notifications-chat-docs-and-files), [Use Docs, Files, Search, and Links](04-employee-guide.md#6-use-docs-files-search-and-links)

## Search and Links

What it does:

- Employee and department search and autocomplete.
- Channel and message search.
- Document search.
- File search.
- Calendar event search.
- Mobile search entry points.
- Canonical resource links for cross-platform navigation.

Common tasks:

- Search for a person, department, channel, message, document, file, or event.
- Open a shared TechOffice link.
- Recover from sign-in, access denied, or not-found states.

Related guides: [Confirm the Active Workspace](03-admin-guide.md#2-confirm-the-active-workspace), [Use Docs, Files, Search, and Links](04-employee-guide.md#6-use-docs-files-search-and-links)

## Mobile App

What it does:

- Authentication, invitation acceptance, SSO callback, password reset, PIN login, and PIN setup.
- Chat, channels, direct messages, threads, voice messages, and voice calls.
- Notifications and push registration.
- Tasks, project details, task creation, ritual details, settings, and evidence-oriented task views.
- Calendar, event details, event creation, and booking links.
- More tab for profile, files, docs, search, settings, and navigation diagnostics.
- Shared resource routes for links and notifications.

Common tasks:

- Use Alerts as the mobile daily inbox.
- Respond to chat and calls.
- Submit ritual evidence from the field.
- Open resource links from notifications.

Related guides: [Mobile Daily Routine](04-employee-guide.md#7-mobile-daily-routine), [Check Your Notifications](04-employee-guide.md#2-check-your-notifications)
